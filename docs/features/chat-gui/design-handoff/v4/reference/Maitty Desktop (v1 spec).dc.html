B · Essential for v1

Populated sidebar, streaming turn

  • Loudness ladder. Needs you shows an amber glyph, bold title and the reason. Unread done items get a bold title and a teal dot. Everything else stays at regular weight.
  • Project headers roll up attention (◆1) so collapsed groups still surface it.
  • Finished tool calls collapse to one line with a verb and a count. Click the Explored row to expand it. The running tool stays open with its last 3 output lines.
  • Streaming text ends with a caret. Its status shows in the header badge and above the composer.
  • You can type during a turn. The draft is saved to disk, and Send stays disabled so nothing gets queued or auto-sent.
  • Context is read-only. It shows exactly where and how Codex is running.
